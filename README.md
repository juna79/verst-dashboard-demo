# Verst Carbon — Verification Layer Demo

## Overview

This is a simple interactive demo showing how a **verification layer** can sit on top of existing carbon market workflows.

It is not a registry, not MRV, and not a trading platform.

It is a **buyer-facing layer** that makes project data:

* visible
* verifiable
* easier to understand

---

## What this shows

The demo walks through a carbon project from a buyer’s perspective:

* Project overview
* MRV timeline (Monitoring → Reporting → Verification → Issuance)
* Report integrity check (hash + verification)
* Certificate view
* Simple project impact + story

---

## Why this matters

Carbon markets already have:

* MRV systems
* verification standards (e.g. Verra, Gold Standard)
* registries

But buyers still struggle to:

* understand projects
* trust what they’re seeing
* engage deeply

This layer focuses on:

> making the output of MRV actually usable

---

## Key idea

Systems run as they already do.

This simply:

* anchors key outputs (reports, certificates, data)
* creates a clean audit trail
* surfaces everything through a simple interface

---

## Tech

This is a lightweight front-end demo:

* HTML / UI mock
* no backend
* no real blockchain integration (conceptual only)

---

## How to view

Once deployed via Netlify:

Open the site and click through:

* Timeline → see how each stage is verified
* Report → check integrity + verification flow
* Certificate → view issued credits
